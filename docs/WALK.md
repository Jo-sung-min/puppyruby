# 함께 걷는 산책방

우리 집의 **강아지 산책시키기** 또는 메뉴 **산책시키기**로 들어갑니다. 주소는 `/play#walk`입니다.

## 사용 흐름

1. 산책 프로필에 `쿠키엄마`, `쿠키아빠` 같은 별명을 저장합니다. 선택으로 입력한 나이와 별명은 다른 견주에게 보입니다.
2. 기존 산책방에 입장하거나 방 이름·소개·배경·정원을 정해 방을 만듭니다. 방을 만들면 바로 입장합니다.
3. 위쪽 공원에는 실제 참가자의 강아지가 돌아다닙니다. 빈 공간을 눌러 내 강아지를 이동하고, 아래쪽 채팅창에서 이야기합니다.
4. 참가자의 프로필에서 친구를 신청합니다. 상대가 수락하면 서로 등록한 이름과 사진을 볼 수 있습니다. 친구 목록에서 요청을 수락·거절하거나 친구 관계를 해제할 수 있습니다.

이름과 사진은 선택 항목입니다. 로그인한 회원이 사진을 선택하면 브라우저에서 작은 JPEG로 바꾸고 프리사인드 URL로 S3에 직접 업로드합니다. 확인이 완료되면 CDN 사진을 미리보기로 표시하며 **프로필 저장**을 눌러 반영합니다. 업로드 실패 시 이전 사진은 유지됩니다. 저장소 설정 전에는 사진 없이 프로필을 저장할 수 있고 기존 사진도 유지합니다. 연결 방법은 [이미지 업로드 안내](IMAGE_UPLOADS.md)를 참고하세요.

친구 전에는 별명과 나이만 공개하며, 서버가 모든 참가자·방장·친구 목록·과거 채팅 작성자의 이름과 사진을 현재 친구 관계에 맞게 반환합니다. 친구를 해제하면 이후 조회에서 다시 숨겨집니다. 이미 전달한 CDN 이미지 주소를 복사한 링크까지 회수하지는 않습니다.

## 산책방 규칙

- 정원은 4·8·12명 중에서 선택합니다. 한 견주는 한 방에만 입장합니다.
- 공식 빈 산책방 3개를 제공합니다. 사람이나 대화 내용을 가짜로 채우지 않습니다.
- 방과 프로필·친구 관계·최근 대화는 DB에 저장합니다. 참가자의 접속 상태와 위치를 공유합니다.
- 방 안은 약 2초, 목록은 약 5초 간격으로 갱신합니다. 다른 탭으로 전환하면 갱신을 쉬며, 60초 동안 응답이 없으면 방에서 퇴장 처리합니다.
- 한 번에 500자까지 대화하며 방마다 최근 100개 메시지를 보관합니다. 연속 전송은 1초 간격이고 같은 전송 식별자의 재시도는 중복으로 쌓이지 않습니다.
- 참가자의 강아지는 웹에서 선택한 자신의 강아지입니다. 산책과 채팅은 성장 경험치·하트를 바꾸지 않습니다.

로그인 중에는 회원 계정의 산책 프로필·친구·채팅을 사용하고, 가입 전에는 현재 브라우저의 체험을 사용합니다. 처음 가입하면 체험 산책 프로필을 계정으로 이어가며 다른 브라우저에서도 로그인해 사용할 수 있습니다. 방문자 쿠키 ID와 공개 산책 프로필 ID는 서로 다릅니다. 실행파일 연결은 강아지 게임 정보만 공유하며 산책 프로필·친구·채팅은 전달하지 않습니다. 운영에서는 Vercel 프록시가 AWS Java API에 연결합니다. [배포 안내](DEPLOYMENT.md)를 참고하세요.

## 개발 검증

백엔드 테스트는 서로 다른 사용자, 방 생성·입퇴장, 친구 수락 전후의 공개 범위, 퇴장 후 접근 제한, 정원 동시 입장 등을 확인합니다.

`scripts/verify-walk.mjs`는 프록시를 포함한 여러 사용자 검증입니다. 프로필·방·채팅을 생성하므로 임시 DB를 사용하는 별도 서버에 실행합니다.

```powershell
$env:WALK_TEST_URL = 'http://127.0.0.1:3101'
node scripts/verify-walk.mjs
```

`scripts/walk-ui-fixture.mjs`는 임시 DB에서 화면 확인용 두 번째 참가자를 연결합니다. 먼저 UI에서 `루비와 함께 걷는 오후` 방을 만들고 실행하면 강아지와 인사를 표시하고, 받은 친구 요청을 10초 뒤 수락합니다. 방 이름은 첫 번째 인수로 변경할 수 있습니다. 10분 후 자동 퇴장·종료합니다.

2026-09-12 검증: 웹 프로덕션 빌드·타입 검사, 서버 테스트 23개, 서로 다른 사용자 5명의 프록시 통합 확인 77항목을 통과했습니다. 별도 임시 DB에서 실제 UI 방 생성·채팅 전송·친구 수락 후 이름/사진 공개·해제 후 숨김을 확인했고, PC·390px·320px 화면과 모바일 Enter 전송을 검토했습니다. 실제 사용자의 프로필·채팅 데이터에 테스트 내용을 넣지 않았습니다.
