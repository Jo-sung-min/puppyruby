# 견종과 도트 무늬 관리

참고 이미지 두 장의 30개 견종을 소개 페이지, 우리 집 도감, 관리자 도트 설정과 뽑기 보상 목록에 등록했습니다. 도트 스타일은 기존 50종에 **산책 도트(`meadow`)**를 더한 51종이며, 견종별 귀·얼굴·털과 기본 무늬를 표현합니다. 소개와 도감은 한 페이지에 12개씩 보여 줍니다.

산책 도트는 네 발로 서서 고개를 돌린 자세, 진한 외곽선과 단계별 털 음영을 사용합니다. 관리자 → 도트 스타일의 **사모예드로 미리보기**에서 선택하고, 전체 또는 견종에 적용 후 저장합니다. 다른 견종과 곰돌이형·여우형, 색상·무늬 설정도 지원합니다. 강아지 그림은 배경과 글자 없이 투명하게 표시합니다.

## 시바견 무늬 10종

관리자 → 도트 스타일 → 시바견에서 일반·흑·백·적·참깨·회색·파티·흑백·아이보리·초코 시바를 미리 보고 종류로 추가할 수 있습니다. 추가한 종류의 색상과 모양은 다시 수정할 수 있으며, 견종에 적용하고 저장하면 사이트에 반영됩니다. 미리보기나 종류 추가만으로 서버 설정을 변경하지 않습니다.

종류는 견종별 20개, 전체 140개까지 저장합니다. 기존 곰돌이형·여우형과 직접 무늬 설정도 사용할 수 있습니다.

## 기존 강아지와 유료 뽑기

기존 여섯 견종의 저장 번호를 유지하고 새 견종을 뒤에 추가했습니다. 키우던 강아지의 견종, 성장, 이름과 꾸미기는 유지됩니다.

새로운 24개 견종은 관리자 뽑기 설정에 등급별 후보로 추가되며 최초 가중치는 0입니다. 기존 상품 가격과 확률을 자동으로 바꾸지 않습니다. 관리자 → 뽑기·상품에서 새 후보의 가중치를 조정하고 저장하면 해당 견종도 유료 뽑기에 등장합니다. 고객에게 표시되는 확률은 저장된 가중치에서 계산합니다.

## 운영 반영

프런트와 서버 JAR를 함께 배포합니다. 기존 실행파일 사용자는 새 견종을 지원하는 갱신된 PuppyRuby.exe를 다시 다운로드합니다. 관리자 도트 선택은 웹의 공통 외형 설정이며 실행파일에는 기본 도트 그림이 포함됩니다.
