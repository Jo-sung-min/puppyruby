# PuppyRuby 서비스 토대

## 서비스의 중심

강아지를 좋아하는 사람이 웹사이트에서 소중한 친구를 만나고, 짧은 돌봄을 통해 마음을 쉬게 하는 공간입니다.
등급은 명령 수행 능력을 표현하며, 강아지의 귀여움이나 소중함을 제한하지 않습니다.

## 첫 흐름

우리 집(루비 + 하트 1,000) → 밥·놀기·휴식 → 명령 연습 → 경험치 쌓기 → 등급 올리기.
새 가족 만나기 → 분양 결과 확인 → 우리 집에서 돌보기.
옷장 → 대상 강아지 선택 → 털색·눈동자·액세서리 미리보기 → 저장.
강아지 도감 → 우리 가족 / 전체 견종 → 등급으로 찾아 선택.

## 데이터와 등급

| 등급 | 분양 확률 | 명령 성공률 | 다음 단계 |
|---|---:|---:|---|
| N | 60% | 45% | XP 100 → R |
| R | 28% | 65% | XP 100 → SR |
| SR | 10% | 80% | XP 100 → SSR |
| SSR | 2% | 95% | 최고 등급 |

포메라니안·토이 푸들·말티즈·시바 이누·웰시 코기·비글의 분양 확률은 각각 1/6입니다. 견종과 등급은 독립적으로 추첨합니다. 중복 견종도 개별 ID를 가진 새로운 강아지로 합류하며, 가족은 최대 100마리입니다.

## 등급별 배움

- N: 앉아, 누적 1개.
- R: 손과 엑셀 기본 단축키 6개, 누적 8개.
- SR: 기다려, 엑셀 작업 단축키 4개, 한글 기본 단축키 6개, 누적 19개.
- SSR: 돌아·빵, 엑셀 고급 단축키 2개, 한글 고급 단축키 5개, 누적 28개.

우리 집의 질문창에서 `엑셀 붙여넣기 단축키 알려줘`라고 물으면 `Ctrl + V다 멍!`처럼 답합니다. 배운 명령은 수첩에서 바로 요청하고, 잠긴 명령은 필요한 등급을 확인합니다. 승급 후 새 명령이 자동으로 열립니다. 질문은 경험치나 재화를 주지 않으며, 모르는 질문에는 추측한 조합을 답하지 않습니다. 공식 Windows 도움말로 검증한 `shared/commands.json`을 웹 서버와 실행파일이 함께 사용합니다. 웹과 실행파일의 등급·경험치는 따로 저장됩니다.

## 돌봄 규칙

| 행동 | 상태 변화 | 경험치 | 하트 | 간격 |
|---|---|---:|---:|---:|
| 밥 주기 | 포만감 +20, 행복도 +5 | +10 | +10 | 30초 |
| 놀아 주기 | 행복도 +20, 에너지 -10, 포만감 -5 | +15 | +15 | 30초 |
| 쉬게 하기 | 에너지 +30 | +5 | +5 | 30초 |
| 명령 성공 | 에너지 -5 | +20 | +10 | 5초 |
| 명령 연습(실패) | 에너지 -5 | +5 | 0 | 5초 |

상태는 0~100 범위입니다. 행동별 대기 시간은 강아지마다 따로 적용합니다. 모든 명령은 하나의 훈련 대기 시간을 공유합니다. 놀기·훈련은 에너지가 부족하면 거절합니다.
접속하지 않은 동안 강아지가 병들거나 사라지는 벌칙은 없습니다. 시간에 따른 상태 감소도 이 토대에는 넣지 않았습니다.
오늘의 선물은 Asia/Seoul 날짜 기준 하루 한 번 +150 하트이며 현금으로 구매할 수 없습니다.

## 확장 순서

1. 실제 계정 인증과 방문자 데이터 계정 이전, 복구 및 다른 기기 연결.
2. 강아지별 명령 동작 스프라이트와 자세별 액세서리 위치, 표현의 다양화.
3. 운영 DB 마이그레이션, API 인증·호출 제한, 백업과 관찰 도구.
4. 분양 연출과 보상 균형 조정, 사용자 피드백을 바탕으로 꾸미기 콘텐츠 확장.
