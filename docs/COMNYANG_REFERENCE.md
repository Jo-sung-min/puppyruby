# 콤냥이 참고 조사 — PuppyRuby 바탕화면 동작

조사일: 2026-09-12. 공식 소개와 사용자가 제공한 파일의 메타데이터·압축 목록만 확인했다. 프로그램을 실행하거나 설치하지 않았으며, 내부 코드·그림·소리를 복사하지 않았다.

## 확인된 제품 기능

| 공식 소개에서 확인한 기능 | 이번 작업과의 관계 |
| --- | --- |
| 커서에 따른 시선 이동, 빠른 커서 이동에 대한 사냥 준비 자세 | 커서 위치와 속도를 구분하는 반응 |
| 들어 올릴 때 늘어나는 모습, 흔들 때 좌우 움직임 | 드래그를 별도 동작으로 취급 |
| 머리 쓰다듬기, 타이핑 앞발, 빠른 입력의 과열 반응, 스크롤 반응 | 입력 종류별 짧고 알아보기 쉬운 몸짓 |
| 영상 감상 중 화면 가장자리에서 조용히 머무는 모드 | 사용자가 집중할 때 방해를 줄이는 설정 |
| 선택 가능한 타이머·스트레칭·물 마시기·메시지 알림 | 필요한 경우에만 표시하는 보조 기능 |
| 색상·무늬 꾸미기, 이름 설정 | 외형과 개인화의 지속성 |

근거: [콤냥이 공식 한국어 소개](https://comnyang.com/ko). 다운로드 안내는 Windows 설치 파일, Google 로그인, 라이선스 등록 절차를 설명한다. [공식 다운로드 안내](https://comnyang.com/ko/download)

소개 페이지의 **시선 이동**은 확인됐다. 강아지 전체가 커서까지 걸어오는 동작, 따라오기/정지 토글, 말풍선의 기본 표시 정책은 이번 조사로 확인하지 못했다. 이 세 가지는 PuppyRuby 사용자의 요청에 맞춰 정하는 자체 동작이다. 실제 실행 화면을 관찰한 결과로 표현하면 안 된다.

## PuppyRuby에 적용할 우선순위

1. **따라오기와 정지**: 커서와 일정 간격을 유지하며 부드럽게 이동한다. 가까워지면 멈추고, 작은 커서 흔들림으로 재출발하지 않도록 정지·출발 거리를 다르게 둔다. 정지 상태에서도 시선 반응은 유지한다. 수치와 이동 규칙은 자체 설계다.
2. **강아지만 보이는 기본 화면**: 이름·등급·조작 안내를 상시 띄우지 않는다. 설정은 우클릭과 트레이에서 연다. 직접 요청한 답변이나 중요한 상태 변화만 잠깐 말풍선으로 표시한다.
3. **사용자 조작 우선**: 드래그와 메뉴 조작 중에는 자동 추적을 멈춘다. 드래그한 자리에 머무르며 다시 따라가기는 메뉴에서 선택한다. 정지 설정은 다시 실행해도 보존한다.
4. **보이는 부분만 반응**: 투명한 여백으로 다른 프로그램의 클릭을 막지 않는다. 강아지 몸체에서 쓰다듬기·드래그가 시작되고, 숨긴 말풍선은 클릭 영역을 남기지 않게 한다.
5. **짧은 몸짓과 조용한 전환**: 키보드·스크롤·클릭 반응은 기존 픽셀 강아지 몸짓으로 전달한다. 입력이 끝나면 자연스럽게 평상시로 돌아가며, 짧은 입력마다 안내 문구가 반복되지 않도록 한다.

이번 우선순위는 공식 제품 기능을 관찰해 얻은 사용성 방향과 PuppyRuby 사용자의 요구를 결합한 제안이다. 콤냥이의 내부 구현·에셋을 재사용할 필요는 없다.
